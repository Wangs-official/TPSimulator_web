# TPSimulator_web

这个项目是给一个公开课用的，没有技术含量，全是AI干的

## 简介

此项目用于练习双绞线的理线顺序，支持 T568A 以及 T568B 线序练习

本项目拥有AI点评以及排行榜功能（本地排行榜），可根据准确率、时间获取AI点评

屏幕下方使用带色线条模拟双绞线，使用鼠标拖动他们到正确的线序位置，然后点击“排列完成”，获得结果

## 使用

本项目可离线运行，直接打开 `index.html` 即可使用

本项目拥有AI点评功能，需要在主页右上角的设置中填写 Deepseek API 密钥，方可使用点评功能
